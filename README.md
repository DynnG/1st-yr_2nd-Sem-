# First-Year, Second-Semester Programming Exercises

A collection of college programming exercises. The repository includes Java source saved in files with descriptive names, often without a `.java` extension.

## Included exercises

- Combinations and factorial calculations.
- Perfect, odious, evil, and unlucky number exercises.
- Password checking and text processing.
- Word triangles, name echoing, and character access.
- Menu and document-printer exercises.

## Run a Java exercise

Install a Java Development Kit. Open the chosen file and find its public class name. Save a local copy with the matching `.java` filename before compiling it. For example, the `Combinations` file declares `public class Combinations`:

```sh
javac Combinations.java
java Combinations
```

The example assumes you have saved the source as `Combinations.java` in your working folder. For other exercises, use their actual class names rather than the repository's descriptive filename.

## Notes

These are separate learning exercises rather than one application. Read each file's prompts and source comments for its input requirements. There is no root build configuration. Preserve the original files when creating local runnable copies.
